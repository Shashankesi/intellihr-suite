## 📖 About The Project

Managing human resources effectively is critical for any growing organization. **IntelliHR Suite** bridges the gap between complex HR operations and a smooth, user-friendly interface. 

Whether you're tracking employee attendance, managing payroll, or organizing departmental data, this suite automates the heavy lifting so administrators and managers can focus on the people, not the paperwork.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

### 🌟 Key Features

- 👥 **Employee Management:** Centralized database for all employee records and documents.
- 🕒 **Attendance Tracking:** Real-time logging of check-ins, check-outs, and leaves.
- 📊 **Insightful Dashboards:** Visual analytics for HR managers to track organizational metrics.
- 🔒 **Role-Based Access Control:** Secure, multi-tiered access for Admins, HRs, and standard Employees.

## 🚀 Getting Started

Follow these instructions to set up the IntelliHR Suite locally.

### Prerequisites

* npm
  ```sh
  npm install npm@latest -g
Installation
Clone the repository

Bash
git clone [https://github.com/Shashankesi/intellihr-suite.git](https://github.com/Shashankesi/intellihr-suite.git)
Install NPM packages

Bash
npm install
Set up your environment variables in .env

JavaScript
MONGO_URI='ENTER YOUR MONGODB CONNECTION STRING'
PORT=5000
Start the development server

Bash
npm run dev
💻 Usage
Once the server is running, log in as an administrator to begin adding departments and employee profiles.

Admin Dashboard: Access at /admin to view company-wide statistics.

Employee Portal: Access at /portal for individual users to check schedules and request time off.
