# IntelliHR Suite

You are a Senior Full Stack Software Engineer, Software Architect, UI/UX Designer, Product Designer, and Enterprise Application Developer.

Your task is to build a production-ready, enterprise-grade AI-powered Employee Management System (Smart HRMS) using the MERN Stack.

This project should look like a real software product used by companies like BNP Paribas, Deloitte, Accenture, TCS, Infosys, Cognizant, Capgemini, etc.

The application must have a premium modern UI, excellent UX, secure backend architecture, responsive design, AI integration, dashboards, animations, and enterprise-level code quality.
